# Vijayakumar Portfolio — Version 18

## Files
- `index.html` — page structure
- `style.css` — styling, responsive layout, animations, and scroll progress line
- `script.js` — navigation, scroll progress, theme controls, interactions, and project showcase

## Run locally
Open `index.html` in a browser. For best results, use a local development server such as VS Code Live Server.

## Publish on GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and this README to the root of your public repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The thin neon line at the top of the page grows as the visitor scrolls through the portfolio.


## Add your own profile photo
1. Open the `assets` folder.
2. Add your photo and name it exactly `vijayakumar-photo.jpg`.
3. Use a clear portrait photo; a vertical image works best. The site will display it in the Home section.
4. Keep the filename and folder path exactly as shown: `assets/vijayakumar-photo.jpg`.

If the photo is not added yet, the Home section displays a photo placeholder instead of a CSS-drawn avatar.

## Resume download
The Resume section includes a Download Resume button that points to `assets/Vijayakumar-Resume.pdf`. Replace that PDF with your latest resume using the same filename. Keep it inside the `assets` folder so the download works on GitHub Pages.
